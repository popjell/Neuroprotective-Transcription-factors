Methods

Raw counts were summed by donor and neuronal subtype. ROAST tested MS versus control within each subtype; q values use Benjamini-Hochberg correction within the method across testable subtype/list comparisons. Singscore used ranked, normalized donor expression; donor-level tests compare MS versus control and adjust for region in Trobisch when both regions are represented. Singscore q values are corrected within the method across testable subtype/list comparisons. Volcano plots use gene-level q values across subtype-by-gene tests and show −3 to 3 log2 fold change and 0 to 10 on −log10(p). Trobisch cortical samples overlap Schirmer samples; subtype labels and expressed-gene sets differ. Detailed report · Complete Trobisch gene-set results.
