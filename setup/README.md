# WSL environment

The working repository is `/home/jathav/lab/Neuroprotective-Transcription-factors`.

Start a session with:

```bash
cd ~/lab/Neuroprotective-Transcription-factors
source setup/activate.sh
```

This activates the project Python and project R library, including when you change into study folders before running their scripts. Starting R at the repository root also reads `.Rprofile`.

Dependencies are listed in `setup/requirements.txt` and `setup/install_r_dependencies.R`. Installation logs and version inventories are under `setup/logs/`. These packages were reconstructed from the scripts; the original Linux environment was not version-locked in Git.

To verify R after installation:

```bash
Rscript setup/verify_r_environment.R
```

Run analysis scripts in their documented order and working directory. Intermediate files can be regenerated by earlier scripts. External atlas inputs such as Trobisch `meta.tsv`/author Seurat objects and the Jakel, Schirmer and Fagiani count caches are referenced as inputs, but their producers are not included in the tracked scripts. Existing result CSVs remain available.

Cytoscape 3.10.5 and Java 17 are installed under `~/lab/tools/`. For scripts 8/9, start the application in a second WSL terminal:

```bash
cd ~/lab/Neuroprotective-Transcription-factors
bash setup/start_cytoscape.sh
```

Then, from the analysis terminal, `Rscript setup/verify_cytoscape.R` checks the API connection and creates/removes a temporary three-node network. The migration verified this connection using an isolated virtual display. The test process has been stopped; the application is installed for normal interactive use. Script 8 allows skipping Cytoscape, and script 9 requires the layout prepared in step 8.
